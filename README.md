# gerador_de_lancamentos

Conversão de um relatório financeiro para lançamento em sistema contábil.
Geração dos lançamentos no layout padrão SCI para a linha Visual Sucessor.

## Pré-requisitos

- Python 3.10+
- Windows ou Linux Debian-based (x64)
- ~50 MB de espaço em disco

## Como compilar

Execute o script correspondente ao seu sistema operacional:

- **Windows:** `build.bat`
- **Linux:** `build.sh`
